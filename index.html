1

設定偵測框

把零件放在治具上，在畫面上拖曳畫出一個框，框住斜槽所在的內凹區域就好（不用整個零件），之後偵測都只分析框內畫面。已提供一個置中的預設框可以直接試用。
2

校正正確角度

已拍攝：0 筆
尚無校正樣本
把「正確方向」的零件放在治具上，點「拍攝校正樣本」3～5 次（可以每次微調一下零件的擺放，讓校正涵蓋治具實際的公差範圍），程式會自動算出目標角度與建議容許誤差，你也可以自己調整容許誤差。
3

設定檔（部署到其他裝置）

校正好後點這裡下載 config-R.json，跟 index.html 放在同一資料夾一起上傳到 GitHub repo，之後任何裝置打開網頁都會自動套用這組偵測框與角度設定，不用在該裝置上重新校正。
4

即時檢測

需完成上方偵測框與角度校正才能開始。NG 狀態若持續未排除，每 3 秒會再響一次長音提醒。
以 OpenCV.js（邊緣偵測＋直線角度量測）於瀏覽器本機執行，所有影像皆不會上傳到任何伺服器。判斷依據是量出來的實際角度數值，不需要收集大量樣本訓練 AI 模型。適合部署於 GitHub Pages 等純靜態託管服務。
